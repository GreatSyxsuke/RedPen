Tip: click a line to edit it — a small bar appears to change size or make it bold. Empty a box to erase that text. Added text has a red handle you can drag to reposition it.

Drop in a PDF to start editing

Best on PDFs that already contain real text (exported from Word, Pages, Google Docs, most invoices & forms). Scanned documents are images with no text to grab.

How it works
1. Open a PDF — each page renders below.
2. Click a line of text to rewrite it. Clear it to delete it.
3. Use Add text to place new text anywhere.
4. Hit Export edited PDF to download the result.
Edits work by covering the original text and redrawing your version on top — so it shines on white pages and simple layouts. Rotated text, tight columns, and exotic embedded fonts may shift slightly. Redrawn text uses a close standard font (Helvetica / Times / Courier).
